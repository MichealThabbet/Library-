ابصالية آدام ثان على الهوس الاول
تعالوا أيها الشعب : نجتمع بفرح : لنسبح الرب : أنه بالمجد قد تمجد.
جدد حياتنا : بالفضائل : وكن لنا عونا : وخلاصا.
لأنك أنت إلهنا : فخلصنا بقوتك : وأعظم مراكبه المختارة : غرقها في البحر.
قوات العدو : طرحها في البحر : يمينك يا رب : تمجدت بالقوة.
المجد لالهنا : الرب اسمه : بكثرة مجدك : حطمت مقاومينا.
كثيرة هي مراحمك : لأن تلك الأمواج : قد تجمدت بقوتك : في وسط البحر.
هوذا الشعوب الشريرة : قد أهلكتها جميعًا : وأهديت : شعبك.
لك القوة : والبركة والتسبيح : من في الألهة : يشبهك يا رب.
يسوع المسيح إلهنا : الذي قد تمجد : بني اسرائيل : كانوا يسيرون على اليابس.
ثم قد سج إسرائيل : ورنم وسكان : فلسطين : قد أخذهم الرعب.
ولما سمعوا : بعظمة اسمك : خاف كل : سكان كنعان.
مريم النبية : ابتدأت تبارك الرب : مع كل النساء : بالدفوف والتسابيح.
وظللهم الغمام : وتابوت العهد بالخيمة : إلي أن اوصلهم : برية سيناء.
مبارك أيها الآب : رب القوات : بقطع قد قطع : ماء البحر.
وقد خلص شعبه : من البحر الأحمر : وصنع عجائب : في وسط مصر.
وأيضا سبحوا ورتلوا : لرب القوات : بني إسرائيل : قد عبروا البحر.
أفواه الجميع : تسبح لاهوتك : أيها المسيح إلهنا : العظيم كل حين.
تأمل واسمعنا : وكن لنا عونا : ونجنا من التجارب : كصلاحك.
ارتفعت بالحقيقة : أكثر من عساكر : الملائكة : أيتها القديسة مريم.
هوذا قد صرت وسيطا : أمام مخلصنا : أيها النبي موسي : الكوكب العظيم.
الله الغير المنظور : والغير المدنو منه : المتسربل بالنور : نسبحه ونباركه.
قدوس انت يا رب : في كل شيء : اعطنا نعمتك : الان وكل أوان.
أيها المخلص ارحم شعبك : أيها السيد العظيم : من أجل والدة الإله : وموسي النبي.
يا ملك الدهور : المسيح إلهنا : أنر لنا : بقوة لاهوتك.
