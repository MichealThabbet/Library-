أُزيلت نسخ الاستخراج المكررة والملفات المشفرة المستبدلة بمحتوى واضح. ملفات DEX الثلاثة وتفريغ تعليماتها والمكتبات الأصلية محفوظة كمرجع للكود. نسخ DEX ليست تطبيقًا جاهزًا لاستخدام الموارد المعدلة؛ المصدر القابل للتعديل يحتوي تعديلات قراءة المحتوى الواضح. لم يُبنَ تطبيق جديد. استرجاع Java ليس كاملًا لجميع الدوال، ولم تُختبر وظائف التطبيق على جهاز.

روابط الخدمات القديمة استُبدلت بعناوين غير تشغيلية، والشعارات بموارد محايدة، لتجهيز المشروع لإضافات المالك. سجل Git السابق لم يُحذف؛ التنظيف يخص الملفات الحالية في الفرع.
