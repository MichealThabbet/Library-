# محتوى مضاف من Coptic-Liturgy-App-main

المصدر: `incoming/Coptic-Liturgy-App-main/Coptic-Liturgy-App-main/assets/files/` في نفس المستودع. هذه الملفات تتضمن نصوص مدائح وعشية العذراء والتوزيع السنوي، مع فهرس CSV بعدد الشرائح وبصمات الملفات. حُفظت الملفات السبعة الكاملة ببايتاتها. ملف `praise_1_الإضافات_فقط.json` يحفظ الشريحتين اللتين لا تتكرران في `praise_1_complete.json`.

استُبعدت ملفات القوائم والإعدادات وعناوين الأقسام فقط. بعض حقول `image` و`background_image` في JSON تشير إلى صور غير موجودة في المصدر؛ النصوص نفسها محفوظة، ولم تُربط بعد بواجهة البرنامج. لم تُضف أكواد Flutter لأن برنامجنا الحالي يستخدم Java، ولم يُعدّل حساب الأبقطي. تطابق النصوص فُحص آليًا بعد توحيد الحروف العربية والمسافات، وقد تختلف الصياغات المتقاربة.
