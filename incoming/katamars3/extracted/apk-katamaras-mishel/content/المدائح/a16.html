القديس أبو فانا

 على مدى الدهور

+ فى مدينة قصر هور

بنيوت آفا فينى

قائم شيخ وقور

والنساك المجاهدين

+ فى وسط القديسين

بنيوت آفا فينى

أب مرتفع أمين

غرسٌ أخضر قد صار

+ كان أبواه أبرار

بنيوت آفا فينى

نخلة حلوة الأثمار

وبجهاد شديد أضاف

+ عاش الشباب بعفاف

بنيوت آفا فينى

رصيد أضعاف أضعاف

وأطعم بيده الجوعان

+ كسا كل عريان

بنيوت آفا فينى

وزار السجين المهان

فتش عنه بأتعاب

+ اشتهى الكنز الخلاب

بنيوت آفا فينى

فنال القديس وأصاب

وعلى باب المغارة

+ الوحدة كانت سكناه

بنيوت آفا فينى

الله أنبع مياه

وصلاة بكل اقتدار

+ بعرق ودموع البار

بنيوت آفا فينى

وصوم ليل ونهار

ولبسه من الألياف

+ وكان أكله الكفاف

بنيوت آفا فينى

فزاد كل الأوصاف

جذب سائر الأرواح

+ عطر زكى فاح

بنيوت آفا فينى

محب كل كفاح

فى المكان قد جاء

+ سراج لامع وضَّاء

بنيوت آفا فينى

وعلى الجبل أضاء

حنان على الملهوف

+ قلبه رقيق عطوف

بنيوت آفا فينى

يجبر كل مقصوف

بآباء أبرار رهبان

+ صار بستان مليان

بنيوت آفا فينى

يسبحون بنغم ألحان

النوع فيه غالى

+ برج حمام عالى

بنيوت آفا فينى

يهيمون فى الأعالى

حياتهم عاشوا بكمال

+ وصايا وتعاليم بجلال

بنيوت آفا فينى

ورفضوا محبة المال

للمرضى دون عناء

+ نال مواهب شفاء

بنيوت آفا فينى

وأقام ميتًا بجلاء

وعلم كل الأسرار

+ عرف كشف الأفكار

بنيوت آفا فينى

وشهد إفرام إجهار

بالنسك صار محنى

+ جسده شاهد يحكى

بنيوت آفا فينى

وبمدحه زاد فرحى

واسأل يسوع ربنا

+ اطلب عنا يا أبانا

بنيوت آفا فينى

لغفران خطايانا

الساهر دائمًا عنا

+ ويحفظ لنا أبانا

بنيوت آفا فينى

أبنا (……) بطركنا

يحفظ أسقفنا المحروس

+ وتسأل عنا القدوس

بنيوت آفا فينى

الأنبا (…….)
